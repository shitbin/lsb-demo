# 레퍼런스 무드보드 — 사용법
목적: 좋은 레퍼 이미지를 모아 **생성 앵커(style reference)**로 직접 박는다. (텍스트 프롬프트 재호출 대신)
활성 위치: `LSB_AD_ENGINE/library/004_moodboard_library` (파이프라인이 읽는 곳). legacy `LSB_Ad_Datas/레퍼런스_무드보드`는 보관용.

## 흐름
1. `00_inbox_컬링용/`에 이미지 파일을 **배치 드래그**로 때려박는다. (채팅 말고 이 폴더에)
2. 이수빈이 inbox에서 **마음에 안 드는 거 삭제**(컬링).
3. 클로드가 남은 것을 아래 **9개 테마 버킷**으로 분류 + 리네임(`<번호>_pinterest_<id>.<ext>`):
   - `01_타이포_CJK포스터/`   — 한글·CJK 타이포 주도 포스터
   - `02_타이포_영문포스터/`  — 영문 타이포 주도 포스터
   - `03_미니멀_에디토리얼/`  — 여백·정제된 미니멀 편집
   - `04_포토_에디토리얼/`     — 사진 주도 에디토리얼(거리·인물·일상)
   - `05_필름그레인_인물무드/` — 필름그레인·무디한 인물
   - `06_드리미_플레어_자연/`  — 드리미 플레어·자연·풍경
   - `07_일러스트_아니메/`     — 일러스트·애니풍·페인터리
   - `08_제품_오브제/`         — 제품·오브제 스틸
   - `09_그래픽_추상콜라주/`   — 그래픽·추상·콜라주·UI
4. 분류본을 planner(STEP 0.55 무드보드 그라운딩)·image-crafter(G6 레퍼 업로드)·treatment-builder가 style 레퍼로 사용.

## 규칙
- 한 폴더 안에서 파일명만 봐도 알게 클로드가 리네임(번호 prefix).
- 분류 기록은 `_분석/manifest.json`(파일→버킷) · `index_map.json`. 취향 분석은 `_분석/스타일DNA_*.md` 참조.
- 버킷은 느슨한 취향 그룹 — 애매하면 지배적 스타일로. 양보다 '취향 일치'.

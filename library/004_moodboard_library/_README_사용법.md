# 레퍼런스 무드보드 — 사용법
목적: 좋은 레퍼 이미지를 모아 **생성 앵커(style reference)**로 직접 박는다. (텍스트 프롬프트 재호출 대신)

## 흐름
1. `00_inbox_컬링용/` 에 이미지 파일을 **배치 드래그**로 때려박는다. (채팅 말고 이 폴더에)
2. 이수빈이 `00_inbox_컬링용/`에서 **마음에 안 드는 거 삭제**(컬링).
3. 클로드가 남은 것을 아래 테마 폴더로 분류 + 태깅:
   - `01_타이포_에디토리얼포스터/`
   - `02_필름그레인_무드/`
   - `03_드리미_일러스트_플레어/`
   - `04_프리즘컬러_건축공간/`
   - `05_팔레트_패션무드/`
4. 분류본을 treatment-builder의 style 레퍼로 연결.

## 규칙
- 한 폴더 안에서 파일명만 봐도 알게 클로드가 리네임함.
- 분석/계획은 `_분석/` 참조.
- 15~30장이면 충분. 양보다 '취향 일치'.

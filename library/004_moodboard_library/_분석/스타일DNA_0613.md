> ⚠️ 파일은 디스크에 안 남아서 파일명 기준 정리는 못 함. 아래는 '무엇이 좋았나'의 패턴.

## 핵심 DNA — 왜 이게 "AI 냄새 안 나"고 좋은가
1. **타이포가 주인공.** 절반 이상이 강한 타입을 이미지와 겹치고/찢고/왜곡해서 배치. 단순 예쁜 렌더가 아니라 **그래픽 디자인**이다.
2. **질감·불완전성.** 그레인, 찢은 종이, 붓터치, 렌즈플레어, 진짜 재질(유리블록·콘크리트·잔디).
3. **컨셉(위트)이 폴리시보다 위.** 모자이크 보틀, 들판의 의자, 감시HUD — 아이디어가 먼저 있고 비주얼이 따라온다.
4. **자신감 있는 레이아웃 + 여백.** 비대칭, 큰 네거티브 스페이스.
5. **뚜렷한 색 정체성.** 뮤트 어스톤 아니면 볼드 프리즘. 어중간한 채도 없음.
6. **에디토리얼/포스터/샤오홍슈/한국 인디 감성** + 아니메-드리미가 서브플레이버.
7. **빛 자체가 소재.** 플레어, 프리즘, 골든 블룸.

> 큰 발견: AI냄새 제거 = "사진 실사화"만이 아님. **이수빈 취향의 ~절반은 그래픽/에디토리얼/포스터(타입+콜라주+컨셉)**다. 심지어 일부 레퍼(신카이풍·글래스블록)는 AI로 만든 것 같지만 **의도·질감·플레어가 살아서** AI티가 안 난다. → 목표는 'AI 도구 회피'가 아니라 **의도성·질감·아트디렉션**.

## 룰북 v1 → v2 보정 방향
v1은 전부 '필름 실사 프리셋'이었음. 취향의 절반(그래픽 포스터)을 못 담음. v2는 **2기둥 구조**로 간다:

### 기둥 P — 포토그래픽 룩 (클러스터 ②③④ 커버)
- v1 프리셋 P1~P6 유지. 단 추가: `lens_flare_bloom`(드리미), `prismatic_color_light`(빛이 소재), `anime_illust_film`(신카이풍 일러스트 톤).

### 기둥 G — 그래픽/에디토리얼 레이아웃 (클러스터 ① 커버 — 신규)
- 타입 처리: 세리프×산세리프×손글씨 믹스 / 타입을 이미지 위에 겹치기·찢기·왜곡 / 큰 타입을 히어로로.
- 콜라주: torn_paper, cutout, doodle_overlay, HUD/감시그래픽, 스티커.
- 이건 이미지 생성이 아니라 **장표/후처리 타이포 레이어**에서 구현 (treatment-builder가 이미 타입을 후처리로 분리함 → 거기에 이 어휘를 주입).

## 레퍼런스 앵커링 설계 (네가 원한 "박아버리기")
현재: 텍스트 프롬프트 저장→재호출. 
바꿈: **라이브러리 이미지를 style reference로 직접 생성에 주입.**
- 각 컷 생성 시 planner가 컷 tone에 맞는 레퍼 이미지 1~2장을 라이브러리에서 골라 Higgsfield `generate_image`의 medias[](style/reference)로 전달.
- 인물 일관성=마스터 캐릭터시트(기존), **룩(그레인·색·플레어·구도)=style 레퍼**가 담당.
- 결과: "매번 긴 프롬프트 다시 짜기" → "진짜 이미지에 앵커 + 가벼운 구조 프롬프트". 이게 AI냄새를 근본에서 줄임.
- 전제: 라이브러리에 **실제 파일**이 있어야 함(앵커로 넘길 바이트). 그래서 폴더에 파일이 들어와야 함.

## 라이브러리 규모 — 크롤링 불필요
수천 장 긁을 필요 없음. **15~30장 잘 고른 것 + 앵커링**이 스크랩 더미보다 낫다.
- 채우는 법(최소노력): 핀터레스트 저장본을 폴더에 **배치 드래그**(한 번에 수십 장, 10초). 내가 자동 분류+태깅.
- 보완: 컬링 끝나면 우리 룰북으로 **하우스 스타일 레퍼**를 직접 생성해 라이브러리에 추가(저작권 0, 100% 사용가능).

## 내러티브 구조

생일 알림 후크(인식) → 주인공이 '29'를 찾기 시작(질문 'WHERE IS 29') → 일상 곳곳의 사물에서 '29'를 연쇄 발견하는 빠른 오브제 몽타주(전개) → 발견의 기쁨을 춤으로 표출(감정 전환) → 더 넓은 도시·사람들의 '29'로 확장(절정) → 모든 '29'가 모자이크로 집결한 뒤 주인공의 29번째 생일 케이크로 수렴('29 IS EVERYWHERE / 29를 찾습니다') → 브랜드 워드마크 마무리(브랜드 각인)

**구조 유형:** cross_cutting_montage

**Creative Device:** recurring_numeral_motif_hunt (일상 속 '29' 보물찾기) + birthday_payoff + kinetic_editorial_typo

**핵심 카피:** 질문형 후크 'WHERE IS 29' → 테마 선언 '29 IS EVERYWHERE' → 브랜드 슬로건 '29를 찾습니다'. 후크 알림 '29 KYOKA님의 29번째 생일을 축하해요'. 브랜드명 '29CM'의 숫자 '29'를 크리에이티브 엔진으로 사용한 네이밍 기반 펀.

**인사이트:** 브랜드명 '29CM'의 '29'를 일상 곳곳에서 무한히 마주치게 만들면, 추상적 셀렉트숍 정체성이 '내 삶 어디에나 있는 친근한 존재'로 각인된다 — 숫자 하나가 브랜드 회상의 훅이 된다.

**제품 역할:** 29CM = '당신 곁의 라이프스타일'을 큐레이션하는 셀렉트숍; '29'는 브랜드가 일상에 스며 있음을 상징.

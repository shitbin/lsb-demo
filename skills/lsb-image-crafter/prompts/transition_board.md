# Transition Board — prompt template (single canvas)

A flashy camera-movement transition (whip_pan / morph / strong push_in or pull_out / 360_spin /
match_action / dolly_through) is generated as **one canvas** holding three beats left-to-right:
**[end of cut N] | [apex of the transition] | [start of cut N+1]** — separated by thin white gutters,
same world / lighting / protagonist (master sheet) across all three.

References (`params.medias`): master sheet + the cut N slice + the cut N+1 slice + moodboard refs (G6).
Same gates as the scene board (G1 declined_preset, G2 full-field beats, G3 composition, G4 fg/mg/bg,
G5 text policy, G7 model/preset lock).

This board is **not sliced** into the storyboard — it stays whole on the transition page (deck) or feeds
the i2v transition clip (video). Per-type motion patterns: REFERENCE/transitions.md (author on demand if
absent — describe the apex as a single visual: e.g. whip_pan = "horizontal motion-blur streak across the
frame, subject smearing left-to-right"; morph = "the two subjects' silhouettes dissolving through each
other"; push_through = "camera diving into a dark foreground object that fills frame").

# layered-collage-protocol.md — 레이어드 콜라주 레퍼런스 처리 (3단 분리)

> **단일 출처(canonical).** analyzer·treatment-builder·video-crafter 세 스킬이 공유한다.
> 적용 대상: **원본(베이스) 이미지 위에 여러 이미지 조각이 콜라주처럼 겹쳐 올라가는 연출**
> (예: GMA 2018 식 — 한 인물 얼굴 위에 서로 다른 크기·각도·크롭의 사각 사진 조각들이
> 불규칙하게 겹쳐 레이어감을 만드는 키비주얼). 한 프레임 안에 여러 장면/조각이
> 동시에 존재하는 **분할(panel)과는 다른** 구조 — 분할은 칸막이로 *나란히*, 콜라주는
> 베이스 위에 *겹쳐서*.

## 0. 절대 원칙 (한 줄)

**생성 모델에게 "이 콜라주를 한 장으로 만들어라"라고 시키지 않는다.**
생성 = 개별 소스 확보 / 후처리 = 위치·비율·레이어 합성 / 영상 = 개별 요소 모션, 으로 **3단 분리**한다.
목표는 단순 합성이 아니라 레퍼런스의 **레이어감·편집 리듬·콜라주 구조·정보 밀도·시각 밀도**를 재현하는 것.

## 1. 단계 1 — 이미지 생성 (개별 소스, 따로따로)

한 프레임에 여러 조각이 겹치는 레퍼런스를 발견하면 **각 조각을 개별 이미지로 따로 생성**한다.
- 분리 예: 배경이 되는 **원본 인물(베이스)** / 눈 클로즈업 / 머리카락 / 옷 디테일 / 질감(천·종이·금속) / 보조 그래픽.
- 이 단계에서 완성된 콜라주 한 장을 억지로 뽑지 않는다 — **합성에 쓸 소스를 안정적으로 확보**하는 게 우선.
- 각 소스는 product-lock·마스터시트·일관성 규칙을 그대로 따른다(인물 조각은 해당 인물 마스터시트 reference).
- 파일 네이밍: `collage_<컷id>_base.png`, `collage_<컷id>_frag01_eye.png`, `..._frag02_hair.png` …

## 2. 단계 2 — 트리트먼트 프리뷰 합성 (Python/Pillow/OpenCV)

개별 소스를 **후처리 도구로 한 프레임에 배치**해 트리트먼트용 **프리뷰/콘셉트 프레임**을 만든다(최종 영상 소스가 아니라 *연출 방향 제시용*).
- 베이스 이미지 위에 여러 사각 조각을 **겹쳐서** 배치. 조각마다 **서로 다른 크기·위치·비율·레이어 순서(z-order)**.
- **너무 정렬된 그리드처럼 보이지 않게** — 약간 불규칙한 콜라주 느낌(미세 회전 ±2~6°, 살짝 어긋난 정렬, 겹침 허용).
- 조각 경계: 얇은 흰/종이 테두리 또는 드롭섀도우로 "콜라주 종이 조각" 질감(레퍼런스 톤에 맞춰).
- 강조 텍스트/그래픽(라벨·연도·해시태그)은 별 레이어로 위에 — 카피 원문 보존(R5: 한국어는 한글).
- 합성 헬퍼: `build_treatment_template`에 `collage_preview(base, fragments[], boxes[])` 패턴 사용 가능(없으면 Pillow `paste`+mask로 즉석 구현). 결과는 트리트먼트 컷 페이지의 키비주얼/씬 보드로 삽입.

## 3. 단계 3 — 실제 영상화 (개별 레이어 모션)

최종 영상은 **한 장으로 고정 합성하지 않는다.** 각 조각을 **개별 레이어/영상 요소**로 다룬다.
- 베이스 위에 작은 조각들이 **순차 등장 / 미세 이동 / 스케일 변화 / 컷 리듬에 맞춰 인(in)**.
- 조각별로 **opacity·scale·position·crop·slight rotation·parallax**를 따로 제어.
- 각 조각은 작은 비율로 올라오되 전체적으로는 **하나의 콜라주 프레임**처럼 읽히게.
- 구현: 베이스 i2v 클립 + 조각 PNG들을 ffmpeg `overlay`(시간차 enable·`scale`·`rotate`·`fade`)로 합성하거나, 조각별 짧은 모션 후 합성. (i2v로 콜라주 전체를 한 번에 움직이려 하지 말 것 — 레이어 제어가 사라진다.)

## 4. 단계별 책임 (스킬 매핑)

| 단계 | 스킬 | 산출 |
|---|---|---|
| 0. 인식·기록 | **lsb-ad-analyzer** | 레퍼런스가 레이어드 콜라주면 `panel_layout.type="layered_collage"` + `base`(베이스 묘사) + `fragments[]`(각 조각: 내용·대략 위치·크기비율·z·회전) 기록. 단순 분할(나란히)과 구분. |
| 1. 개별 소스 생성 | **lsb-treatment-builder** Phase 3 | 조각별 t2i 개별 생성(콜라주 한 장 금지). |
| 2. 프리뷰 합성 | **lsb-treatment-builder** Phase 3/4 | Pillow/OpenCV로 불규칙 콜라주 프리뷰 → 트리트먼트 삽입. |
| 3. 영상 레이어 모션 | **lsb-video-crafter** | 조각별 overlay·opacity·scale·parallax. |

## 5. 확인 질문 (임의 진행 금지)

어떤 요소를 개별 이미지로 분리할지 애매하면 **임의로 진행하지 말고 질문**한다. 특히 이 넷의 구분이 안 서면 먼저 확인:
1. **배경으로 쓸 원본(베이스) 이미지**
2. **위에 얹을 보조 이미지 조각들**
3. **텍스트/그래픽 요소**
4. **실제 영상에서 움직여야 하는 요소**

## 6. 요약

콜라주형 레퍼런스 → **개별 이미지 생성 → 후처리로 프리뷰 합성(불규칙) → 영상에선 개별 레이어로 작게 배치·모션**.
"한 번에 콜라주 한 장" 지시 금지. 레이어감·리듬·밀도를 재현하는 게 목표.

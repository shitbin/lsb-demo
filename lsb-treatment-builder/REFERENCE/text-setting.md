# text-setting — 덱 카피 조판(타이포세팅) 시스템

> **트리트먼트 PDF에 PIL로 찍히는 텍스트(카피)를 "미적으로" 앉히는 규칙.** typography-in-image(이미지에 텍스트 박기)와 별개 — 이건 *슬라이드 위 글자*의 줄바꿈·강조·크기·정렬을 자동으로 결정한다. 범용. (Phase 4 빌더 텍스트 렌더에서 사용.)

## 0. 문제

현 빌더는 카피를 한 덩어리로 박고, 폭을 넘으면 **글자 단위(by char)로 기계적 줄바꿈**한다. 그래서 의미가 어색하게 잘리고, 강조어 색 분리도, 크기 위계도, 정렬 판단도 없다. 결과가 "정보는 맞는데 안 예쁜" 슬라이드.

**원칙: 카피는 '문장'이 아니라 '연출된 텍스트'다.** 의미 단위로 끊고, 핵심구만 색·크기로 띄우고, 내용 성격에 맞는 정렬을 고른다.

## 1. 네 축 (typeset 시스템)

### 축 1 — 의미 단위 줄바꿈 (clause line-break, NOT by char)
- 글자 수로 자르지 않는다. **절·구·호흡 단위**로 끊는다.
- 한국어 끊는 자리: 쉼표(`,`) / 연결·대조 어미(`~이 아닌,` `~지만` `~며` `~고` `~다가`) / 조사 경계 / 따옴표 구(`'...'`) 앞.
- **대조 구문("A가 아니라 B")은 A와 B를 다른 줄로** 분리해 대비를 시각화.

예 (사용자 예시):

```
입력:  데이터 부족은 불편이 아니라 '잠깐 끊기는 단절'
출력:  데이터 부족은 불편이 아닌,        ← line 1 (도입·조건)
       '잠깐 끊기는 단절'                ← line 2 (결론·강조)
```

### 축 2 — 포인트 컬러 (한 블록 1강조)
- 한 텍스트 블록에서 **핵심구 1개만** 브랜드 포인트 컬러. 나머지는 기본색(흰/크림).
- 핵심구 = 인사이트의 결론 / 펀치 / 베네핏 / 브랜드 키워드 (보통 대조의 B항·마지막 줄).
- 예: `'잠깐 끊기는 단절'` → 포인트 컬러(민트) · `데이터 부족은 불편이 아닌,` → 기본색.
- **1블록 1강조** 엄수(2개 이상이면 위계 붕괴).

### 축 3 — 크기 위계 (role → size)
한 블록 안에서 역할별 크기 차등으로 시선 흐름을 만든다.

| 역할 | 크기(base 대비) | 색 |
|---|---|---|
| 결론·핵심구 | **1.0 (가장 큼)** | 포인트 컬러 |
| 도입·조건절 | 0.62 | 기본색 |
| 부연·근거 | 0.38 | 회색 |

예: `'잠깐 끊기는 단절'` 84pt 민트 / `데이터 부족은 불편이 아닌,` 52pt 크림 / (부연) `"데이터 다 썼다"의 그 멈칫하는 순간` 30pt 회색.

### 축 4 — 정렬 스마트 판단 (center vs left)

| 정렬 | 언제 | 근거 |
|---|---|---|
| **center** | 임팩트 카피·슬로건·디바이더·선언(1~2줄) / 시네마틱·감성 톤 | 한 메시지를 가운데서 친다 |
| **left** | 논리 전개·다단 설명·근거 여러 줄(3줄+) / 서비스·정보 톤 | 읽기 흐름·시작선 고정 |

판정 규칙(휴리스틱):
- 줄 수 ≤ 2 **and** 선언/카피형 → **center**
- 줄 수 ≥ 3 **or** 설명·논리·리스트 → **left** (좌측 기준선 고정, 강조구는 크기/색으로 위계)
- 트랙 톤 가중: 시네마틱(B)·표지·E.O.D = center 선호 / 서비스(A) 전략·정보 = left 선호.

## 2. 처리 파이프라인 (빌더 함수 제안)

`typeset(text, role, theme, box) -> [{text, size, color, align, weight}]`

1. **split_clauses(text)** — 쉼표·연결/대조 어미·따옴표 구로 의미 단위 분할.
2. **assign_roles** — 각 줄에 intro / conclusion / sub 역할 + emphasis span(핵심구) 지정.
3. **style** — role→size(축3), emphasis→point color(축2), 기본=기본색.
4. **align** — 축4 규칙으로 center/left. box 폭 초과 시 의미 단위 내에서만 재분할(글자 단위 금지).
5. **render** — 줄별 크기·색·정렬·줄간격(leading=size×1.18) 적용.

**경량 마크업(옵션, planner가 카피에 부여하면 정확도↑):**
- `//` = 강제 줄바꿈 힌트 · `*강조구*` = 포인트 컬러 지정 · `__크게__` = 사이즈 업.
- 예: `데이터 부족은 불편이 아닌,// *'잠깐 끊기는 단절'*` → 줄바꿈+강조 자동.
- 마크업이 없으면 split_clauses 휴리스틱으로 추정.

## 3. 적용 위치

전략 비트(beat) 페이지 · 컨셉 카피 · 키비주얼 카피 · 클로징 슬로건 — **텍스트가 주인공인 모든 페이지.** (콘티 자막은 짧아 단순 처리.)

## 4. 자가검사
1. 카피가 글자 단위로 어색하게 잘렸나? → 의미 단위로 재분할.
2. 한 블록에 포인트 컬러 2개+? → 1개로.
3. 모든 줄이 같은 크기로 밋밋한가? → 결론/도입/부연 위계 부여.
4. 긴 설명을 center로 가운데 들쭉날쭉? → left + 기준선 고정.
5. 대조 구문인데 한 줄에 뭉쳤나? → A/B 줄 분리.

## 5. 한 줄 요약

**카피를 한 덩어리로 박지 말고 연출하라 — 의미 단위로 끊고, 핵심구 하나만 색·크기로 띄우고, 선언이면 가운데·설명이면 좌측. "정보는 맞는데 안 예쁜" 슬라이드를 없앤다.**

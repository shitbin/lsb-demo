## 4. 신규 기능 — 컷 t2i/i2v 복제 프롬프트 (경계)

`recreation_prompts`: 컷마다 시작프레임 재현 t2i(~300단어) + 그 스틸을 원본 컷 모션으로 영상화하는 i2v. 사양: `lsb-ad-analyzer/REFERENCE/frame-recreation-prompts.md`.

> **경계:** craft(구도·렌즈·조명·색·모션)와 **자막·카피 원문**은 충실히 보존(copywriting 기준 — 짧은 카피·수치 verbatim, 장문 고지만 excerpt). 셀럽 *얼굴 사진수준 복제*·실제 *로고 마크*만 generic(초상·상표). 카피 텍스트 속 브랜드명·모델명은 자막이라 그대로. → 특정 광고 1:1 복제가 아니라 재사용 craft 레시피, cross-pollination 입력.
>
> **6개 entry 백필은 보류**(사용자 요청 — 원본 비디오·자막 확보 후). 현재는 사양서 + 워크드 예시 2개만.

## 5. 적용 순서 & 검증
1. §1의 15개 파일을 스킬 폴더에 덮어쓰기.
2. 라이브 데이터셋(§2)은 이미 반영 — 추가 작업 없음.

4. 인덱스 확인: `<DATASET>/index/by_industry.json` 키가 finance/automotive/... 영문, `_meta.language=="en"`.
5. analyzer로 새 entry 생성 시 search_keywords가 영문 토큰 + `recreation_prompts` 채워지는지.
6. **(JSON-first) analyzer 새 entry가 strict `.json`으로 저장되고 `python3 -c "import json;json.load(open(경로))"`가 통과하는지. 데이터셋에 `.py`가 새로 생기지 않았는지(`find <DATASET> -name '*.py'` → index_helper.py 외 0).**

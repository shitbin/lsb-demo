## 0. 이 문서를 읽는 법

- 이 문서는 **"지금 파일에 실제로 들어있는 상태"**만 기술한다. 추측·계획·이 세션에서만 떠돌던 임시 아이디어는 배제했다.

## 5. 4-스킬 파이프라인 개요 (분업 원칙)

- **AI는 후보를 대량 생성, 사람(디렉터)이 미적 판정.** AI는 "좋다/나쁘다"의 미적 판정을 신뢰하지 않는다. 각 비싼 단계 전에 멈추고 컨펌.
- **저작권 안전:** 데이터셋에서 끌어오는 건 Level 2~3 추상화(공식·구조·시그니처). 픽셀 복제 금지. **자막·카피 원문은 보존**(짧은 카피 verbatim). 셀럽 *얼굴 사진복제*·실제 *로고 마크*만 generic — **단, 사용자가 명시적으로 허용하면(예: 성능테스트) 그 세션 한정 사용자 지시 우선**(planner R4 예외).
- **분류 태그는 전부 영문 토큰**(search_keywords 10축 등). KO→EN 별칭표 = `lsb-treatment-builder/REFERENCE/keyword-vocabulary.md`.
- **컨셉의 원천은 planner.** builder/video-crafter는 컨셉을 새로 만들지 않고 받은 걸 시각화·영상화.

## 6. 스킬 상세

### 6.1 lsb-ad-analyzer  (버전 `_2606041200`)

**목적:** 광고 영상 mp4 1편 → **데이터셋 entry 1개**(`<DATASET>/entries/ADV-YYYY-NNN.json` + `_review.md`). "무엇이 찍혔나"가 아니라 **"어떻게 연출됐나"**(움직임·레이아웃·타이포모션·촬영효과·나레이션)를 구조화.

**핵심 워크플로(STEP):**
- STEP 1 — 전 프레임을 **원본 해상도**로 추출(`frames/allframes/`). **컨택트시트(축소 그리드)·다운스케일로 판독 금지.** (`--max-edge`·`--contact-cols` 옵션 쓰지 말 것.)
- STEP 1.5 — Whisper 나레이션 추출(+폴백 1.5-a: 실패해도 자막기반으로 채우고 시각분석 진행).
- STEP 2 — 컷 분할 검증(개별 프레임 직접 비교, 동색 match-cut·split은 수동 식별).
- **STEP 2.5 (이번 세션 신규) — 컷 중간프레임 + 컨택트시트 데이터셋 보존.** 각 컷 duration의 가운데 프레임을 `<DATASET>/entries/<ID>_frames/cutNN_mid.png`로 저장 + `contact_sheet.png` + `frames_index.json`. 스크립트 `scripts/ad_midframes.py`(allframes에서 복사 — 추가 디코딩 없음). **왜:** 텍스트만 저장하면 다른 세션이 *한 프레임 안 분할/멀티패널 레이아웃*을 못 그린다.
- STEP 3 — 전역 시그니처(capture_style·camera_signature[wiggle_3d 등]·color_grade).
- STEP 4 — **전 프레임 전수 판독**(컷별 7가지: 정적·레이아웃·타이포모션·카메라·소품/색/포징·동적·고증).
- STEP 4.5 — 시각 인벤토리 5축(visible_elements·texture·lighting·color_analysis·style_prompt) + **4.5.6 recreation_prompts**(컷별 t2i_start_frame·i2v_motion·i2v_params).
- STEP 5~5.6 — 상위구조·카피·오디오 종합 + 역추정 10축(search_keywords 영문) + 인덱스 자동 갱신(인라인 파이썬 스니펫).
- STEP 6 자가검사 → STEP 7 출력(strict JSON로 저장 후 json.load 검증).

**이번 세션 신규 강제(요약):**
- 컷 중간프레임/컨택트시트 보존(STEP 2.5) + entry에 `frames_dir`·`contact_sheet_path`·각 shot `mid_frame_path`.
- **`panel_layout` 스키마**(분할/멀티패널 컷): type=filmstrip/split/grid/pip/collage/**layered_collage**/typo_zone_split + panels[](rect %·size_ratio·content·text_in_panel·z·rotation_deg).
- **recreation_prompts의 t2i는 컷당 ≥500단어**(이전 ~300 → 디테일 소실로 구현 불가했음). 부록 B에 **Part 13(분할/멀티패널 패널 분해)** 규칙.
- `layered_collage`(베이스 위 조각 겹침)는 공유 프로토콜(§6.5)로 처리.

**파일:** `SKILL.md`(부록 A=스키마, B=프레임복제 t2i/i2v 사양, C=영문 vocab) · `schema.md`(스텁 — 부록 A로 병합됨) · `scripts/ad_midframes.py`(신규) · `scripts/index_helper.py` · `REFERENCE/frame-recreation-prompts.md`(스텁 — 부록 B로 병합).

### 6.2 lsb-ad-planner  (버전 `_2606041500`)

**목적:** 데이터셋 entry들 + 브리프 → **cross-pollination**(카테고리 교차참조)으로 표절 위험 없는 새 광고 기획안(컨셉 후보 N안·카피·컷리스트 = treatment.json). AI가 후보 대량 생성, 사람이 판정.

**절대 규칙 R1~R9** (전문은 SKILL.md 상단):
- R1 표절 회피 / R2 (생략) / R3 브랜드 자산 선리서치·고정(정확 hex) / **R4 브랜드 IP 생성 금지 — 사용자 에셋 우선 (+이번 세션 추가: 사용자 명시 예외 시 그 세션 한정 우선)** / **R5 한국어 카피·나레이션은 한글로만**(로마자 발음표기 금지) / R6 역량 단정 금지(목록 조회 검증) / R7 다중 인물·공간은 명단부터(character_pool·narrative_structure·subject_identity) / **R8 (신규) 산출물 다운스트림 용도 1줄 명시**(제품 reference 시트=순수 비주얼, 메인카피=한글) / **R9 (신규) 비싼 단계 전 컨펌·도구 예고 텍스트 금지**.

**워크플로 핵심:**
- STEP 0.0 데이터셋 resolve → STEP 0 브리프 폼(AskUserQuestion). **0.1 첫 질문에 종횡비(9:16/16:9/1:1) 명시 질문 필수**(추론 금지) + **product_spec_lock**(제품 불변 스펙 — 그리드 수·비율·각인 — 정의해 모든 이미지 프롬프트에 verbatim).
- **STEP 0.5 비주얼 레퍼런스 분석:** 표면 토큰(technique/vfx 라벨)만 읽지 말고 **color_analysis·lighting·texture·style_prompt를 정독해 '무드의 물리근거' 추출**. style_prompt 형용사 그대로 인용("light grain"을 "heavy sepia"로 바꾸지 말 것). 데이터셋 있어도 무드보드 1장 컨펌.
- STEP 0.6 브랜드·제품 선제 웹리서치(필수) → STEP 2~3 컨셉 생성·cross-pollination(가중치 동일0.2/인접0.5/원거리1.0/대조1.2, 와우컷 하드밴) + 카피 cross-pollination(copy_bank).

**파일:** `SKILL.md` · `schema.md`(cross-pollination 가중치 맵 §3 = **단일 출처**, analyzer→treatment 키 매핑 §5).

### 6.3 lsb-treatment-builder  (버전 `_2606041330`)

**목적:** planner 기획안 → 캐릭터 마스터시트 → 씬보드(멀티패널) → 슬라이스 → **장표(트리트먼트) PDF**. 컨셉을 새로 잡지 않는다.

**Phase 0~7:**
- Phase 0 입력검증·작업폴더 + **전략 입력 필수**(strategy_spine: brief/insight+evidence/strategy/concept_rationale/brand_right/payoff — 비면 빌드 금지).
- Phase 1 Plan 해체(컷별 30+ 필드, analyzer shots와 동일 스키마) + Deck Style 결정 + 1.4 서사·인물 판정.
- Phase 2 마스터 캐릭터시트(인물마다 각각).
- Phase 3 씬보드/트랜지션보드/슬라이스 + **3.1-b (신규) 레이어드 콜라주 분기**(§6.5).
- **Phase 4 Deck Build — 이번 세션 대폭 업그레이드:**
  - **캔버스 4K(3840×2160) 기본.** `build_treatment_template.py`의 `SCALE=2`. 1080p 납품 금지.
  - **에디토리얼 레이아웃 시스템(코덱스 리디자인급 기본값)** = `REFERENCE/editorial-layout.md` + 코드 `build_treatment_template.py §8`:
    - 아키타입: `cover_split`(텍스트 좌/히어로 이미지 우) · `two_col`(논증 좌/크림 PROOF 카드·이미지 우) · `fullbleed_kv`(풀블리드 키비주얼) · `cut_board`(확정컷 썸네일 그리드).
    - **팔레트 토큰**(`THEME_EDITORIAL`: bg/surface=크림/ink/muted/point/line) — 브랜드 hex로 덮어씀. 정보 페이지엔 **크림 surface** 적극 사용(전부 다크 금지).
    - **이미지 의무(IMAGE MANDATE):** 표지·키비주얼·컷보드·씬 페이지는 실제 이미지(`hero_stills/`·`확정컷/`) 합성. `assert_images_present()`가 0장이면 빌드 보류.
    - 좌측정렬 위계 기본(중앙정렬은 슬로건 1~2줄만).

- 이 세션 후반에 **도구 호출이 간헐적으로 깨져 코드가 텍스트로 노출되는 런타임 현상**이 있었다. 이는 스킬 로직과 무관한 세션/런타임 아티팩트이며, 새 세션에선 재발하지 않을 것으로 본다(깨끗한 컨텍스트 권장 이유). 스킬 파일에는 영향 없음 — 모든 변경은 위 §7대로 정상 반영·검증됨.
- 위 §13은 *맥락 메모*일 뿐, 스킬 규칙이 아니다.

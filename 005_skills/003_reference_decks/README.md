# 우수 트리트먼트 예시 (reference_decks)

세 종이 서로 다른 **용도×톤 트랙**(`REFERENCE/presentation-rules.md` §0·§5)을 대표하므로, 새 덱의 톤이 정해지면 가장 가까운 예시의 시그니처(배경·포인트컬러·타이포 위계·이미지 배치·여백)를 끌어와 재현한다. **픽셀 복제 금지 — 디자인 문법만 학습**(cross-pollination과 동일 원칙).

## 공통으로 배울 점 (세 종이 공유하는 문법)
- **다크 또는 라이트 중 하나로 커밋 + 단일 포인트 컬러 1개**(민트/시안/골드). 색을 흩뿌리지 않는다.
- **표지 = 초대형 한글 디스플레이 + 영문 키커/서브태그**의 2단 위계. 한글이 주인공, 영문은 보조 라벨.
- **헤드라인은 의미 단위로 끊는다**(예: "배달비, // 안 내는 걸로.") — `build_treatment_template.typeset`이 강제하는 바로 그 조판.
- **한 페이지 한 메시지**, 넓은 여백. 풀블리드 이미지는 표지·키비주얼 등 임팩트 페이지에 한정.
- 포맷(가로 16:9 vs 세로 9:16)은 매체에 맞춰 결정 — 숏폼이면 세로(ex02)처럼 텍스트존/이미지존 분할.

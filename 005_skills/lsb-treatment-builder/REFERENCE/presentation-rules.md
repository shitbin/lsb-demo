## 0. 큰 그림 — "용도(format)"가 디자인을 결정한다
같은 회사가 **세 가지 용도**에 따라 완전히 다른 디자인 언어를 쓴다.

| 용도 | 언제 | 디자인 트랙 |
|---|---|---|
| **기획안 (아이디어 제안)** | 컨셉 N안 의사결정용 | 다크 임팩트 — 검정/CI색 풀블리드 디바이더 + 한 페이지 한 자막 + 키비주얼 1장 |
| **트리트먼트 (연출 확정)** | 채택안 컷 단위 구체화 | (시네마틱물) 순흑 1장 레터박스 콘티 / (서비스물) 화이트 정보형 + 3열 콘티 그리드 + 표 |
| **PPM (제작 직전)** | 스태프·일정·소스 점검 | 화이트 정보형 + Agency Board(전 컷 일람) + 옵션(메인/ALT) |

추가로 **톤 트랙 2개**가 디자인 색을 가른다:
- **시네마틱(양반김)**: 순흑 BG, 크림/세리프 이탤릭, 1장 레터박스. 인물드라마·프리미엄·식음료.
- **서비스/펀(우리은행·FIJI)**: 검정 BG + CI색(블루/오렌지/그린) 디바이더, 한 줄 자막 컷, 5열 콘티 그리드. 셀럽·금융·생활·통신.
- (클라이언트 맞춤: CJ처럼 브랜드 컬러 라운드카드로 갈아탈 수도 있음.)

## 1. 전 덱 공통 문법 (반드시 이식)
1. **16:9 가로 고정.**
2. **표지** = 단색(또는 CI색) 풀블리드 + 거대 타이포(대각선/중앙) + "기획안/Treatment/PROPOSAL" + 날짜(25.xx) + 스튜디오 로고. AI 이미지 덱은 표지/하단에 **"본 자료의 모든 이미지는 AI로 생성되었습니다"** 고지.
3. **상단 중앙 킥커 라벨** — 작은 레터스페이싱 대문자 또는 `*섹션명` 이탤릭 세리프(STRATEGY/CONCEPT/DOOH/DIGITAL/*Director's Conti/*Ref. ...). 그 아래 중앙에 본문. **수직 위계 일정.**
4. **챕터 디바이더 = 단색 풀화면 + 초대형 타이포 + 마침표(.)** — `A.` `B.` `C.` 또는 `CONCEPT A.`. 글자 자체가 비주얼.
5. **한 페이지 한 메시지/한 구절** — 핵심 카피를 한 번 통째 제시한 뒤, 페이지마다 한 구절씩 흘려 **영상 리듬을 PDF에서 미리 체험**시킨다(양반=운문, KT=슬로건, 우리은행=나레이션). 이게 페이지 수가 많아지는 이유.
6. **화자 분리 콘티 캡션** — `#` 또는 `#숫자` 한 줄 설명 + `자막)`(강조색/볼드) vs `NA)·VO)·O.V)·중계 NA)`(흰색/별색) 괄호 화자표기.
7. **이미지 수 = 의도** (§3 결정표).
8. **전체 흐름 요약 1장** — 컨택트시트(양반 30컷 4행) 또는 종합 컷보드(우리은행 6~9분할) 또는 Storyboard Summary.
9. **SCHEDULE** = 캘린더/간트, 끝에서 두 번째.
10. **`E.O.D` 클로징** — 표지와 같은 배경색 풀블리드.
11. **3-앵커 러닝 텍스트** — 좌(상단/세로) 프로젝트 코드·`AI commercial 2025`, 우(세로) `STUDIO FREEWILLUSION`, 하단 중앙 `© 2025 @studio freewillusion. All rights reserved.`
12. **국문 = 굵은 고딕(본문체), 영문 슬로건/섹션명 = 세리프 이탤릭** 혼용. 이 대비가 시그니처.

## 2. 카피 규칙
### 2.1 톤 분기 (콘텐츠 성격별)
- **시네마틱·헤리티지(양반·공군·신세계)**: 운문/시적. 의인화("국은 속을 덥히는 배려"), 예의·격·품격 어휘. 영문 슬로건 이탤릭("WHERE KOREAN TASTE BEGINS"). 클로징 한 마디 임팩트("필승!").
- **서비스·펀(우리은행·FIJI·전북대)**: 구어체·밈·외침. 브랜드명 워드플레이(우월적사고/혜택우월주의, 다되G·빠르G·편하G, "댑니다=됩니다"), 의성어, 물음표 후킹("진짜 원인은?"), 수치 클레임("99.9% 제거").
- **감성 드라마(CJ웹드라마)**: 장르라벨("블랙코미디 X 성장드라마") + 굵은 로그라인(물음표) + 시놉 **변화아크(자아 희미→사건→위기→각성)** + **엔딩 함축 한 줄**("합합은 못 해도, 현장은 지킨다").
- **공익 콜앤리스폰스(보건복지부)**: 질문×반박 매트릭스("누가 그래?/난 아니야?") + 신조어 슬로건("술.스.라.이.밍") + 위클라이맥스.
- **티저(KG INSTEROID)**: 미스터리 한 줄을 토막 분산 후 회수("한계라는/벽은 없다/…/KG").

### 2.2 공통 카피 메커니즘
- **핵심어만 강조색**(블루/오렌지/보라/형광노랑) 또는 볼드, 나머지는 무채색.
- 영문 컨셉 키워드는 **세리프 이탤릭 + 마침표**("Concept." "30\"cinematic.")로 격조.
- 3단어 키워드 병렬("미래지향. 시네마틱. 표범상징. 프리미엄.") — 단어+마침표 staccato.
- 트리트먼트는 **길이별 카피 3단 비교표**(기존→30s→15s)로 압축 과정을 노출(FIJI COPY (RE)WRITE).

## 3. 페이지당 이미지 수 — 결정표 (★핵심)
| 페이지 목적 | 이미지 수 | 규칙 |
|---|---|---|
| 디바이더·키워드 매니페스토·컨셉 스테이트먼트·슬로건 빌드업·운문 브리더·로그라인·시놉시스 | **0장 (텍스트 only)** | 단색 배경, 타이포가 비주얼. 한 페이지 한 메시지. |
| 나레이션/자막 콘티 컷 (기획안) | **0장** | 검정 BG 중앙 한 줄 자막. 영상 1초≈1슬라이드. |
| 키비주얼·후킹·제품 히어로·단일 레퍼런스·시네마틱 서사 컷 | **1장 풀블리드(서비스) / 1장 레터박스(시네마틱)** | 카피는 이미지 위 오버레이. 시네마틱은 여백 띄워 극장 프레임. |
| 같은 씬 다른 앵글·디테일 / A안 vs B안 / before-after / 과거 vs 현재 / 레퍼런스 | **2장 비교** | 화살표·라벨 병치. |
| 무드 강조·바리에이션 / 캐릭터 카드 / DOOH 옵션 | **3장 (1대형+2스택 또는 3-up)** | |
| 옵션 1행 비교 / 톤앤무드 시안 | **4장 (4-up·2×2)** | |
| 컨셉 종합 무드보드 / 키이미지 모음 | **6장 그리드** | |
| 콘티 그리드(서비스 트리트먼트·기획안) | **5열(10~13컷) / 3열(6컷)** | 컷 위 회색 헤더바 + #번호 + 자막/NA 2줄. |
| 스토리보드 시퀀스(공군·G-EYE·전북대) | **4×2=8 / 4×4=16 / 5열** | 타임코드·단계 내러티브 동반. |
| 톤앤무드 대량 레퍼런스 | **8~17장 그리드** | "다양함" 과시할 때만. |
| 전체 흐름 요약(컨택트시트·Summary) | **전 컷 썸네일 1장** | 덱당 1회 필수. |

**원리: 숫자가 많을수록 무드/추상/요약, 1장일수록 서사/임팩트/제품. 풀블리드는 드물게, 여백으로 띄우는 게 기본.** 정보밀집 페이지(그리드/표)와 임팩트 페이지(1장/텍스트)를 **교대**시켜 호흡을 만든다.

## 4. 내용 분배 규칙
- **단위 반복 균등화**: 한 아이디어/작품/버전을 *고정 페이지 세트*로 반복. 우리은행=컨셉당 [디바이더→Concept타이틀→자막컷 다수→Key image→Video technique→Ref.→종합보드], CJ=작품당 [소개 1p+시놉 1p], FIJI=버전당 [라벨→5열그리드→키비주얼], 양반=[운문→6키워드→컨셉맵→Ref.→콘티30→컨택트시트].
- **기획안**은 컨셉 N안 병렬(보통 3~5안), 끝에 SUMMARY로 수미상관.
- **트리트먼트**는 채택 1안을 컷 단위로(콘티가 덱의 50~62%).
- 카피:이미지 비율 — 컨셉/서사 페이지 50:50~80:20(텍스트 우위), 콘티/무드보드 20:80(이미지 우위).

## 5. 색·타이포 — 트랙별 스펙 (재빌드용)
### 트랙 A — 서비스/펀 (우리은행·FIJI 식)
- BG: 검정(#000) 기본. 디바이더·표지·E.O.D만 **CI색 풀블리드**(우리=블루 / KT Y=민트 #11E6D8).
- 강조: CI색 하이라이트 단어 + 문장 끝 컬러 점(•).
- 타이포: 한글 초굵은 산세리프(거의 화면 폭), 자막 볼드 중앙. 영문 라벨 세리프 이탤릭 소문자+마침표("Concept." "*Key image." "*Video technique." "*Ref.").
- 디바이더: 블랙/CI색 풀화면 + 초대형 흰 "A." "B." "C." (마침표).
- 콘티 종합: 6~9분할 그리드 + 우측 카피 정리.

### 트랙 B — 시네마틱 (양반김 식)
- BG: 순흑(#000). 표지·E.O.D만 **딥레드(#9E1F1F)**.
- 텍스트: 크림/화이트. 악센트 **빨강**(키워드 마침표 점, 슬로건 별표).
- 타이포: 섹션 = `*Director's Conti` 세리프 이탤릭+밑줄 중앙. 컷헤더 = 이탤릭 세리프 숫자. 운문/캡션 = 흐린 회색 이탤릭. 디렉터 키워드 = 굵은 크림 산세리프 + **줄끝 빨간 마침표**.
- 콘티: **1장 대형 레터박스**(검정 여백으로 띄움) + 상단 컷헤더 + 좌측 `#`캡션 + 하단 중앙 **운문 한 구절**.
- 6대 디렉터 키워드 페이지(텍스트 only) + 컨셉 스테이트먼트 + 컨셉맵 + 컨택트시트(전 컷 4행) 필수.

## 6. 적용 예시 (트랙 선택 → 재빌드 스펙)
한 브리프에 두 컨셉을 다른 트랙으로 가져갈 수 있다(예시):

**서비스/펀 컨셉** = 트랙 A. 표지 CI색 풀블리드 + 거대 타이포 / `A.` 디바이더(CI색 풀, 흰 대문자+마침표) / `Concept.` 세리프 이탤릭 라벨 + 거대 한글 카피 / **자막 컷(0장)**: 검정 BG 중앙 한 줄(핵심어 라임 하이라이트) / **Key image(1장 풀블리드)** + 카피 오버레이 + `*Key image.` 태그 / **종합 컷보드(9분할 그리드)** / E.O.D CI색.

**시네마틱 컨셉** = 트랙 B. 표지 딥레드 대각선 타이틀 / `*Director's Treatment` → **6대 디렉터 키워드**(줄끝 빨간 점) / 컨셉 스테이트먼트 / **콘티(1장 레터박스/페이지)**: 컷헤더(이탤릭 숫자) + `#`캡션 + 하단 **운문 한 구절**을 컷마다 분해 / **컨택트시트**(전 컷 한 장) / E.O.D 딥레드.

> 트랙·구체 카피·운문은 *프로젝트별*로 채운다(여기 §6은 적용 방법의 예시 골격일 뿐, 고정 콘텐츠 아님).

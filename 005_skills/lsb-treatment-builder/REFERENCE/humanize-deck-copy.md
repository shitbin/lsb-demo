# humanize-deck-copy — 장표 문구 휴머나이즈 룰북 (LSB 장표 프로파일 v1.0)

> **출처:** epoko77-ai/im-not-ai "Humanize KR — 한글 AI 티 제거기" v2.0 `quick-rules.md` (MIT License)를
> LSB 트리트먼트 장표·발표 스크립트 텍스트에 맞게 프로파일링한 것. 패턴 ID는 원본과 1:1 호환.
> **적용 지점:** builder Phase 4.2-b(작성 시 회피) · Phase 5 게이트 ⑬(S1 잔존 0 스캔) · Phase 6.1 피치 스크립트.

## §0. 원칙

1. **write-time 회피 우선.** 탐지→수정보다, 쓸 때부터 안 쓰는 게 싸다. 산문을 쓰는 순간 이 룰북이 머리에 있어야 한다.
2. **의미 불변.** 사실·주장·수치·고유명사·직접 인용은 100% 보존. 문체·리듬·표현만 손댄다.
3. **근거 기반.** 탐지된 패턴에만 수술적 수정. 멀쩡한 문장을 취향으로 갈지 않는다.
4. **과윤문 금지.** 기존 텍스트를 수정할 땐 변경률 30% 초과 = 경고, 50% 초과 = 중단·롤백. (새로 쓰는 텍스트엔 해당 없음.)

## §1. 적용 대상 — builder가 *작성하는 산문*만

| 적용 ○ (휴머나이즈 대상) | 적용 ✗ (불가침 — 건드리면 사고) |
|---|---|
| STRATEGY 비트 문단(브리프·인사이트·전략·정당성·기대효과 서술) | **planner 확정 카피 원문** — 헤드라인·태그라인·CTA·자막 카피 |
| 컨셉 설명·도출 논리 문단 | 브랜드명·제품명·모델명·기관명 |
| 섹션 리드문·브리지("앞의 전략을 이렇게 영상으로") | 수치·날짜·가격·단위·법적 고지 |
| 클로징·크레딧 문구 | 큰따옴표 안 직접 인용 |
| `treatment_client_pitch.md` 발표 스크립트(입말 — 특히 엄격) | 영문 vocabulary 토큰(제작 8블록 페이지의 framing·camera_angle 등) |
| 컷 보드 캡션·노트의 서술부 | 업계 표준 영어 약어(KV·CTA·VO·i2v·LLM·API 등) |

> **카피는 왜 불가침인가:** 의도적 대구·반복·리듬·생략은 카피라이팅 *기법*이다. C-8(대구 반복)·E-1(문장 길이) 같은 산문 룰을 카피에 적용하면 카피가 죽는다. 카피 품질은 planner R1(날카로움 게이트)이 관할 — builder는 원문 그대로 조판만 한다(4.2-a typeset).

## §2. 장표 장르 보정 (원본 룰북과 다른 점)

장표·피치 텍스트는 칼럼·리포트가 아니다. 다음은 원본과 달리 적용한다.

- **J-3(불릿 금지) 미적용** — 장표는 개조식·불릿이 정상 문법. 단 불릿 *안의* 문장에는 나머지 룰 전부 적용.
- **C-8(대구 반복) 카피 면제** — 산문 문단에서만 잡는다.
- **E-1(문장 길이 분산) 완화** — 장표 텍스트는 짧아서 무의미. 발표 스크립트·긴 설명 문단에만.
- **G(hedging) 강화** — 장표는 설득 문서다. "~할 수 있을 것으로 기대된다" 류는 칼럼보다 더 치명적. 단언으로 쓴다(단, 법적 리스크 있는 효능·수치 주장은 `fact_check_flag` 관할 — 단언화로 사실을 과장하지 말 것).
- **C-10(콜론 부제 헤딩) 주의 깊게** — "전략: 일상을 멈추다" 식 헤딩 반복은 장표에서 가장 흔한 AI 티. 평서 헤딩 또는 짧은 명사구로.
- **D-4(hype 어휘) 산문만** — 광고 카피의 과장은 기법일 수 있다. 산문(전략 서술)에서 "압도적·획기적" 3회+면 구체 사실로 환원.

## §3. 핵심 패턴 테이블 (원본 quick-rules 전수 · 정의 1줄 + 처방 1줄)

**Do-NOT(탐지·수정 모두 제외):** §1 우측 열 전부.

|---|---|---|---|
| A-1 | "~에 대해(서)" | S1 | 목적격 조사로 직결("X에 대해 논의" → "X를 논의") |

## §4. 자가검증 체크리스트 (게이트 ⑬ — 빌드 전 5초 스캔)

산문 텍스트 확정 직후(조판 전) 점검. 한 항목이라도 위반이면 그 문구만 재작성.

1. **카피 원문·수치·고유명사 100% 보존** — §1 우측 열을 한 글자도 안 건드렸나.
2. **S1 잔존 0건** — D-1~D-7 / A-7·A-8·A-16 / C-5·C-10·C-11 / H-1·H-3 / I-1.
3. **장르 유지** — 전략 장표가 에세이·블로그체로 떨어지지 않았나. 격식 일관(피치는 입말 일관).
4. **단언 확인(G)** — "~할 수 있을 것으로 기대된다" 류가 핵심 주장 자리에 없나.
5. **인공 수사 금지** — 휴머나이즈 핑계로 원문에 없던 비유·문학 표현을 끼워 넣지 않았나.

위반 발견 → 해당 문구만 재작성 → 재스캔(루프 최대 1회, 이후도 미해결이면 사용자에게 보고).

## §5. 장표 맥락 예문 (before → after)

- "본 캠페인은 데이터 분석을 통해 MZ세대의 구매 패턴에 대해 파악할 수 있을 것으로 기대된다."
  → "이 캠페인은 데이터로 MZ세대의 구매 패턴을 읽는다."  (A-2·A-1·A-10·G-1)
- "전략적 함의: 브랜드 자산의 활용" (헤딩) → "브랜드 자산을 어떻게 쓰나" (C-10·F-5)
- "이는 타깃이 강한 구매 의향을 가지고 있다는 점을 시사하는 바가 크다."
  → "타깃은 구매 의향이 강하다." (H-3·A-7·D-2)
- "결론적으로, 본질적으로 이 컨셉은 일상에서 출발한 것이다."
  → "이 컨셉은 일상에서 출발했다." (D-1·D-3·I-1)
- (발표 스크립트) "또한 저희는 차별화된 비주얼을 통해 임팩트를 창출하고자 합니다."
  → "비주얼은 이렇게 다르게 갑니다." (H-1·A-2·명사화)
